# Start session

## Steps

1. Read `AI/README.md` (master router).
2. Read `AI/PRODUCT.md` (locked strategy).
3. Read `AI/PROGRESS.md` (done / next).
4. Open only the relevant `AI/intelligence/*` and `AI/research/*` files for the task.
5. If a module is in scope, check `AI/specs/` status (Draft vs Approved) via `spec-workflow`.
6. If engineering process is unclear, read `using-agent-skills` and pick **1–3** skills from `AI/skills-index.md`.
7. Confirm hard nos still apply; do not scaffold `extension/` or `cli/` until specs are Approved and a plan says so.

## Done when

You can state the current next step from `PROGRESS.md` and which KB/spec files apply — without having loaded all vendor skills.
